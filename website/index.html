Agent Skin Presets for Valorant

Create skin presets, assign them to your agents, and ValoVault applies them automatically the moment you lock in.

Download for Windows View on GitHub

Features

Everything you need to stop manually re-picking skins every game.

Create Presets

Save your favorite combinations of weapon skins as named presets.

Apply Instantly

Swap your whole loadout to a saved preset with a single click.

Agent-Specific Presets

Assign different presets to different agents — one loadout per pick.

Auto-Apply

Enable “Auto Select Agent” and your preset applies as soon as you lock in.

Variants

Create variants of a preset so you don't have to rebuild it per agent.

Gun Buddies & Dark Mode

Buddy support, skin search, premium skins first, and a proper dark theme.

Supported Game Modes

ValoVault applies your presets across every mode you play.

  • Competitive
  • Unrated
  • Custom
  • Skirmish
  • Swiftplay
  • TDM
  • Spikerush
  • Escalation

Get Started

Four steps and you're done.

1. Download

Grab the latest .msi installer from GitHub Releases.

2. Install

Run the installer. ValoVault updates itself from then on.

3. Launch Valorant

Open Valorant and log in as usual.

4. Launch ValoVault

It connects to your Valorant client automatically.

For Developers

ValoVault is open source. Contributions welcome.

Built with a Go backend and a Next.js frontend wrapped in Tauri.

git clone https://github.com/truearken/valovault.git
cd valovault/frontend && npm install
cd ../backend && air          # terminal 1
cd ../frontend && npx tauri dev  # terminal 2
